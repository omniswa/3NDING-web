Welcome to 3NDING

A first post that shows every formatting option the new 3NDING publishing system supports, from headings and lists to tables, quotes and code.

By 3NDING Editorial October 25, 2026 1 min read

In this post

  2. Lists
  3. Quotes

Every post is a Markdown file in content/posts/. Run the build and it becomes a page, a card on the home page, a sitemap entry and an RSS item.

Text and links#

Text can be bold, italic, removed, highlighted or inline code. Link to an internal page or an external site. Press Ctrl + F to search a page.

A subsection#

Use ## for sections and ### for sub-sections. The page title is the only top-level heading.

Lists#

  • Short, scannable items
  • Lists can nest:
    • Nested item one
    • Nested item two
  1. Write the post in the generator.
  2. Save it into the project folder.
  3. Run npm run build.
